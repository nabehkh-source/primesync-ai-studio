# Contributing

Keep changes focused on connection guidance, interface documentation, reproducible examples, and corrections.

For a documentation correction, include the affected page, current behavior, expected wording, and dated evidence. For a tool issue, include the task mode, client, redacted input, and redacted output.

Use synthetic examples. Keep credentials, private source, customer data, and proprietary trading logic out of contributions.

Separate declared capabilities from tested behavior. Do not add performance claims, approval badges, or authentication guarantees without evidence.

No contribution license or open-source server license is established by this repository.
