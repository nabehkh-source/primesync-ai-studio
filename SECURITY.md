# Security and privacy

This repository is for public-facing documentation and synthetic examples. Do not include API keys, OAuth tokens, client secrets, cookies, account identifiers, private strategy code, or customer trade exports in issues or pull requests.

The connected PrimeSync Studio declaration says the tool does not store strategy code, execute submitted code, contact brokers, or place trades. This repository does not independently verify those statements or establish a retention policy.

Only submit code and datasets you are authorized to share. Review the hosted service's current privacy terms before sending sensitive information.

Report suspected security issues through the service's private support channel, accessible from [PrimeSync](https://primesync.me). Do not post exploit details or credentials in a public issue. This document does not promise a response deadline or a vulnerability bounty.
