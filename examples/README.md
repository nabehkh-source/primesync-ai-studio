# Example requests

These are tool argument objects matching the observed input declaration. They are not complete MCP wire messages and were not executed during documentation preparation.

- [New indicator](build-indicator.json): explicit simple rules for a new design.
- [Preserve existing logic](preserve-existing.json): replace the marked placeholder with code you are authorized to submit.

For trade analysis, supply actual CSV text in `datasets`, with the required `asset` and `timeframe` for each dataset. Avoid inventing results or reusing old separate-tool payloads with the current interface.
